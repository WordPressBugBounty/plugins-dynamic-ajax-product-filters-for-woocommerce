== Installation ==

= From your WordPress dashboard: =

1. **Visit** Plugins > Add New
2. **Search** for "Dynamic AJAX Product Filters for WooCommerce"
3. **Activate** the plugin from your Plugins page
4. Configure filter settings in the WooCommerce settings panel under "Product Filters."

= Process of Using AJAX Product Filters for WooCommerce Store =

**Step 1: Configure Product Filters**
1. Navigate to **Admin** → **Product Filters** → **Form Manage**.
2. Enable the options for **Show Categories**, **Show Attributes**, **Show Tags**, **Show Price Range**, and **Show Rating** as needed.
3. Choose a filtering method in the use **URL-Based Filter** section:
   - With Query String (e.g., `?filters`)
   - With Permalinks
   - With Ajax

**Step 2: Add Products and Customize Filters**
1. Add WooCommerce products, categories, attributes, and tags.
2. Use the `[plugincy_filters]` shortcode to display filtering options wherever needed.
3. Customize the filter widget styles via **Admin** → **Product Filters** → **Form Style** tab.

== Frequently Asked Questions ==

= Is This Plugin Compatible With My Theme? =  
Yes. Dynamic AJAX Product Filters for WooCommerce works with standard WooCommerce archive markup and includes selectors for custom product loops, pagination, sorting, and result-count areas.

= How Can I Configure the Filter Options? =
Simply go to the WordPress admin, locate the “Product Filters” section, and customize the filter options based on your store requirements.

= Does the Plugin Support Custom Permalinks? =
Yes, the plugin supports custom permalink structures, allowing filtered pages to align with your store’s permalink setup.

= Is the Plugin Compatible With Variable Products? =
Yes. Dynamic AJAX Product Filters for WooCommerce supports filtering variable products by attributes and supported variation-aware product data where WooCommerce exposes it.

= Does This Plugin Support Shortcode Usage? =  
Yes. Use `[plugincy_filters]` for the full filter set, `[plugincy_filters_single name="pa_color"]` for one filter group, and `[plugincy_filters_selected]` for selected-filter chips. The shortcode builder supports core layout/mobile/selector/URL options, while Pro unlocks drawer, popup, redirect, operator, and full desktop layout controls.

= Can I filter by custom taxonomies, brands, featured products, and product exclusions? =
Yes. The Pro version supports selected custom taxonomy filters, featured product filters, brand taxonomy auto/manual mapping, and exclusion rules for products, categories, tags, brands, and custom taxonomy terms.

= Does it support advanced pagination, AJAX sorting, and custom theme selectors? =
Yes. Pro supports numbered pagination, numbered pagination with previous/next, load more, infinite scroll, AJAX sorting, result-count selectors, product shortcode selectors, and custom selectors for WooCommerce loops or builder loops.

= Can I build filters with Elementor, Gutenberg, and shortcodes? =
Yes. You can use Elementor widgets, Gutenberg blocks, `[plugincy_filters]`, `[plugincy_filters_single]`, `[plugincy_filters_selected]`, and the shortcode builder with layout, mobile, redirect, selector, operator, and URL settings.

= Does the Pro version support WPML? =
Yes. Pro includes WPML compatibility for saved option strings, translated taxonomy/product filter data, language-aware filter caches, and current-language frontend labels.
